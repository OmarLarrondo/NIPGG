\section{Criterios de integración}
Se utiliza el diagrama relacional proporcionado para conservar nombres,
columnas, tipos y marcas de llave. Se respeta incluso el rótulo literal
\texttt{Genrente}, aunque contiene una errata. La asociación
\texttt{Disponer} y la relación \texttt{Administrar} reciben una PK por
pareja de participantes para impedir filas duplicadas. No se agrega una
tabla general de empleados que el diagrama no contiene.

Se dispone de 24 tablas. Se ejecutó el DDL de avance en PostgreSQL~18,
en una base vacía y separada de cualquier restauración. Quedan pendientes
las FK de Partida hacia Máquina y de los dos contactos de técnicos hacia
Técnico. Por esa razón, el SQL se identifica como avance y no como DDL final.
