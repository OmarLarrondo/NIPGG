# Informe de avance

`Practica05_avance.pdf` contiene la identificación del equipo, los dominios
de los módulos disponibles y los pendientes. Se genera desde `reporte/main.tex`
mediante `python3 herramientas/compilar_avance.py`. Se compiló sin desbordamientos
y se revisaron las páginas renderizadas. Los PDF están ignorados por Git.

El informe final `Práctica05.pdf` se generará tras integrar el módulo 02 y
agregar las evidencias reales de restauración. La consigna original permanece
en la raíz de la práctica y no es el informe entregable.
