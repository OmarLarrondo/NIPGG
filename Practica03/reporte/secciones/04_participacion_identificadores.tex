\section{Participación e identificadores}

Las restricciones de participación de las relaciones son:

\begin{itemize}[leftmargin=*]

\item \textbf{Pertenecer}: relación entre \textbf{Sucursal} y \textbf{Máquina}, en este caso la sucursal tiene participación parcial ya que puede que aún no tenga máquinas, si es que abrió recientemente; por otra parte, Máquina debe ser total dado que dice ``Cada máquina pertenece exclusivamente a una sucursal'', lo que implica que las máquinas siempre deben pertenecer a alguna sucursal.

\item \textbf{Trabajar}: relación entre \textbf{Sucursal} y \textbf{Empleado}, en este caso la sucursal tiene participación parcial ya que puede registrarse una nueva sucursal sin personal; por el contrario, el Empleado necesita forzosamente trabajar en alguna sucursal para ser empleado, por lo que tiene participación total.

\item \textbf{Realizarse en}: relación entre \textbf{Sucursal} y \textbf{Recarga}, en este caso la sucursal tiene participación parcial ya que puede haber una sucursal registrada que por x tiempo no se realicen recargas; en cuanto a Recarga, debe ser total dado que para que se realice una recarga debe ser hecha en una sucursal y debe registrar esa sucursal.

\item \textbf{Realizarse en}: relación entre \textbf{Sucursal} y \textbf{Canje}, en este caso la sucursal tiene participación parcial ya que puede haber una sucursal registrada que por x tiempo no se realicen canjes; por otro lado, un canje debe registrar la sucursal en la que se realizó, por ello debe tener participación total.

\item \textbf{Realizarse en}: relación entre \textbf{Sucursal} y \textbf{Visita}, en este caso la sucursal tiene participación parcial ya que puede haber una sucursal registrada que por x tiempo no tenga visitas; por otro lado, una Visita tiene que ser obligatoriamente en una sucursal, por lo que debe tener participación total.

\item \textbf{Disponer}: relación entre \textbf{Sucursal} y \textbf{Premio}, en este caso la sucursal tiene participación total ya que cada sucursal debe tener un inventario de premios, mientras que Premio tiene participación parcial, pues puede haber premios que ya no estén en una sucursal.

\item \textbf{Administrar}: relación entre \textbf{Sucursal} y \textbf{Gerente}, en este caso la sucursal tiene participación total debido a que debe haber siempre un gerente administrando la sucursal; en cuanto a Gerente, este tiene participación total, ya que si el empleado tiene el puesto de gerente debe de 1.~trabajar en una sucursal y 2.~dirigir esa sucursal.

\item \textbf{Corresponder}: relación entre \textbf{Máquina} y \textbf{Juego}, en este caso Máquina tiene participación total ya que cada máquina debe corresponder a un juego y Juego tiene participación parcial ya que puede haber juegos que aún no tengan una máquina.

\item \textbf{Ejecutar}: relación entre \textbf{Máquina} y \textbf{Partida}, en este caso Máquina tiene participación parcial, puede haber una máquina en estado de mantenimiento por lo que no puede ejecutarse, mientras que una partida tiene participación total debido a que debe ejecutarse necesariamente en una máquina.

\item \textbf{Recibir}: relación entre \textbf{Máquina} y \textbf{Mantenimiento}, en este caso Máquina tiene participación parcial porque puede una máquina estar en perfecto estado, mientras que Mantenimiento tiene participación total, pues debe ser obligatoriamente sobre una máquina.

\item \textbf{Registrar}: relación entre \textbf{Partida} y \textbf{Tarjeta}, en este caso Partida tiene participación total debido a que no puede existir una partida si no fue registrada por una tarjeta y Tarjeta tiene participación parcial, pues puede ser recién adquirida y aún no ser usada.

\item \textbf{Recibir}: relación entre \textbf{Tarjeta} y \textbf{Recarga}, en este caso Tarjeta tiene participación total, ya que al obtenerla y registrar se debe realizar una recarga de \$10.00 y Recarga también es total, dado que una recarga debe ser necesariamente dada a una tarjeta.

\item \textbf{Vender}: relación entre \textbf{Tarjeta} y \textbf{Cajero}, en este caso Tarjeta tiene participación total, debido a que su registro depende de que un cajero la venda a un cliente, y Cajero es parcial, puede no vender tarjetas por un tiempo indeterminado.

\item \textbf{Registrar}: relación entre \textbf{Tarjeta} y \textbf{Visita}, en este caso Tarjeta tiene participación parcial dado que puede existir la tarjeta y no necesariamente registrar una visita cada día; por otro lado, Visita tiene participación total ya que solo se registra una visita una vez se usa una tarjeta.

\item \textbf{Poseer}: relación entre \textbf{Tarjeta} y \textbf{Cliente}, en este caso Tarjeta tiene participación total, pues no tiene sentido registrar una tarjeta inactiva, es decir, sin que ningún cliente la use, mientras que Cliente tiene participación total ya que para usar las instalaciones debe tener una tarjeta.

\item \textbf{Realizar}: relación entre \textbf{Cliente} y \textbf{Canje}, en este caso Cliente tiene participación parcial, pues puede ser Cliente recién registrado que no tenga puntos en su tarjeta, y Canje tiene participación total pues un Canje debe ser hecho por un cliente.

\item \textbf{Realizar}: relación entre \textbf{Mantenimiento} y \textbf{Técnico}, en este caso Mantenimiento tiene participación total, pues necesariamente es un técnico el que lo debe realizar y Técnico tiene participación parcial, pues puede que la sucursal donde esté no tenga una máquina en mal estado.

\item \textbf{Reflejar}: relación entre \textbf{Recarga} y \textbf{Cajero}, en este caso Recarga tiene participación total dado que es un cajero el que debe reflejar esa recarga en una tarjeta, mientras que Cajero tiene participación parcial, pues puede aún no haber atendido a nadie.

\item \textbf{Procesar}: relación entre \textbf{Canje} y \textbf{Encargado de premios}, en este caso Canje tiene participación total ya que es Encargado de premios el que procesa la entrega de los premios, mientras Encargado de premios tiene participación parcial pues puede aún no haber atendido a nadie.

\item \textbf{Otorgar}: relación entre \textbf{Canje} y \textbf{Premio}, en este caso Canje tiene participación total pues un cliente realiza un canje siempre para obtener un premio; por otro lado, Premio tiene participación parcial dado que puede haber premios aún no reclamados.

\end{itemize}

\subsection{Identificadores de las entidades}

Los identificadores de las entidades son:

\begin{itemize}[leftmargin=*]

\item \texttt{idCliente}: Cliente.
\item \texttt{numeroTarjeta}: Tarjeta.
\item \texttt{idPartida}: Partida.
\item \texttt{idMaquina}: Máquina.
\item \texttt{idMantenimiento}: Mantenimiento.
\item \texttt{idJuego}: Juego.
\item \texttt{idSucursal}: Sucursal.
\item \texttt{idVisita}: Visita.
\item \texttt{idRecarga}: Recarga.
\item \texttt{idCanje}: Canje.
\item \texttt{idPremio}: Premio.
\item \texttt{CURP}: Empleado.

\end{itemize}
