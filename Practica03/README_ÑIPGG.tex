\section*{Observaciones}

El diagrama y el reporte fueron revisados de manera cruzada antes de generar
el archivo comprimido. La cantidad disponible de cada premio se modela en la
relación \emph{Disponer}, ya que depende de la sucursal. El modelo no utiliza
agregación y especializa a \emph{Empleado} de forma total y disjunta. No se
incluye carpeta SQL porque no es requerida para esta práctica.
