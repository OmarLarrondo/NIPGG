# Diagramas de la Tarea 03

Los diagramas se elaborarán en línea con diagrams.net (draw.io) y sus
exportaciones se guardarán en esta carpeta. Se requieren archivos editables
`.drawio` y sus imágenes `.png`:

- `Ejercicio2a_ER.drawio` / `Ejercicio2a_ER.png` y
  `Ejercicio2a_Relacional.drawio` / `Ejercicio2a_Relacional.png`;
- `Ejercicio2b_ER.drawio` / `Ejercicio2b_ER.png` y
  `Ejercicio2b_Relacional.drawio` / `Ejercicio2b_Relacional.png`;
- los que hagan falta para el Ejercicio 3 (modelos E-R y relacionales).

Al integrar los archivos, comprobar que cada PNG corresponda a su fuente
editable y que nomenclatura, llaves y cardinalidades coincidan con el
reporte.
