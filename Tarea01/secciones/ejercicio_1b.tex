\section*{Ejercicio 1b. Elección de un sistema manejador de bases de datos}
Supón que una empresa en crecimiento necesita implementar un sistema de administración de
bases de datos (SMBD) para centralizar su información operativa (ventas, clientes, inventario y
logística). Elige dos posibles soluciones (p.e., PostgreSQL, Oracle, MySQL, SQL Server, etc.) y
compara sus ventajas y desventajas en términos de: rendimiento ante grandes volúmenes de
datos; escalabilidad a futuro; costos de licenciamiento y mantenimiento; soporte técnico y
comunidad.\textbf{Con base en tu análisis, argumenta cuál solución recomendarías y por qué.}

Para este análisis vamos a comparar dos posibles soluciones: PostgreSQL y Microsoft SQL Server.\\
Respecto al rendimiento ante grandes volúmenes de datos PostgreSQL es muy eficiente en consultas complejas, 
mientras que SQL Server destaca por su optimización para el análisis histórico. Respecto a la escalabilidad a futuro, 
SQL Server ofrece una ventaja mediante su transición hacia arquitecturas híbridas con Azure, 
mientras que PostgreSQL escala verticalmente sin problemas, pero requiere extensiones adicionales para su expansión horizontal. 
La diferencia más grande radica en los costos de licenciamiento y mantenimiento: PostgreSQL es gratuito (Open Source), 
a diferencia de los altos costos por núcleo de SQL Server. 
Finalmente, en cuanto a soporte técnico y comunidad, SQL Server ofrece soporte técnico directo de nivel empresarial con Acuerdos de Nivel de Servicio (SLA) garantizados,
mientras que PostgreSQL se apoya en una comunidad global, requiriendo proveedores externos si se desea un soporte corporativo estricto.

La solución que recomendaría sería PostgreSQL, ya que es un sistema de código abierto, lo que significa que no hay costos de licenciamiento y tiene una gran comunidad de soporte.
Además, PostgreSQL es conocido por su capacidad para manejar grandes volúmenes de datos y su escalabilidad a futuro, lo que lo hace ideal para una empresa en crecimiento. 
Por otro lado, Microsoft SQL Server puede ser más costoso y aunque también es escalable, 
puede no ser tan flexible como PostgreSQL en términos de personalización y adaptabilidad a las necesidades específicas de la empresa.
