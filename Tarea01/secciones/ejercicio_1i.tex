\section*{Ejercicio 1i. De datos a información útil}

\noindent

\vspace{0.3cm}

La simple acumulación de datos no garantiza que estos se conviertan en información útil. Para que los datos puedan utilizarse correctamente, deben estar organizados, estructurados y relacionados de manera adecuada. Además, es necesario garantizar su integridad y protegerlos contra accesos o modificaciones no autorizadas. El objetivo de una base de datos no es únicamente almacenar grandes cantidades de datos, sino facilitar su almacenamiento, consulta y actualización de manera fiable y eficiente.

\vspace{0.3cm}

Tomemos el ejemplo de la institución financiera que necesita almacenar millones de registros relacionados con clientes, cuentas y transacciones. Para que estos datos sean realmente útiles, cada elemento debe tener una estructura definida y estar correctamente relacionado con los demás. Por ejemplo, los clientes podrían tener una o varias cuentas, mientras que las cuentas pueden estar relacionadas con diferentes transacciones. Por esta razón, es necesario definir qué información debe almacenarse de cada cliente, de cada cuenta y de cada transacción, así como la manera en que estos elementos se relacionan entre sí.

\vspace{0.3cm}

La \textbf{organización y estructura} son importantes porque permiten acceder y procesar la información de manera eficiente. Una base de datos correctamente diseñada facilita, por ejemplo, consultar la información de un cliente, conocer las cuentas asociadas a él o revisar las transacciones realizadas.

\vspace{0.2cm}

La \textbf{integridad} también es fundamental. Los datos deben ser fiables y mantenerse consistentes, evitando errores, duplicaciones o relaciones incorrectas. Para ello, los sistemas de bases de datos pueden establecer restricciones de integridad que ayuden a evitar datos anómalos y a mantener la información correcta.

\vspace{0.2cm}

Por otro lado, la \textbf{seguridad} es indispensable en una institución financiera, debido a la importancia de la información que administra. Es necesario controlar quién puede acceder a los datos y qué acciones puede realizar cada usuario. Un sistema de bases de datos puede incluir información sobre restricciones de integridad, privilegios y roles otorgados a los usuarios.

\vspace{0.3cm}

\noindent
\textcolor{unamblue}{\rule{\textwidth}{1.2pt}}

\vspace{0.3cm}

Por lo anterior, podemos observar que almacenar millones de datos por sí solo no garantiza que estos sean útiles. La organización, la estructura, la integridad y la seguridad permiten transformar una gran cantidad de datos en información fiable, accesible y útil para las operaciones y la toma de decisiones de una organización.
