\subsection{Sistema de archivos o base de datos}

Si hablamos del prototipo actual que creamos el sistema de archivos es más adecuado dado que es una solución simple y suficiente para demostrar el funcionamiento del sistema. Sin embargo, para una implementación real y completa de PuellaGame, una base de datos sería más conveniente debido al crecimiento de la información, la necesidad de mantener su integridad, realizar consultas eficientes, controlar el acceso y permitir el trabajo de varios usuarios de manera simultánea.
