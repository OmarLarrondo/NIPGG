\section{Requerimientos candidatos}
% Pendiente: enumerar los requerimientos de alto nivel del caso de uso.

\begin{itemize}
    \item Gestión de entidades: El sistema debe almacenar información específica sobre las sucursales, los premios y los clientes.
    \item Operaciones principales (CRUD): El prototipo debe permitir al usuario agregar, consultar, editar y eliminar información de las sucursales, premios y clientes.
    \item Persistencia de datos: La información capturada debe persistir, lo que requiere que el sistema sea capaz de guardar y leer los datos utilizando archivos .CSV.
    \item Interfaz de interacción: Es necesario implementar al menos un menú interactivo para que el usuario pueda ejecutar las operaciones de gestión mencionadas.
    \item Consultas por identificador: Para la función de consulta, el sistema debe solicitar y recibir la "llave" de la entidad para devolver todos los datos relacionados con la misma.
    \item Validación de entradas: El sistema debe verificar que los campos diseñados para almacenar números únicamente acepten valores numéricos.
    \item Manejo de errores: El código debe incluir un manejo de excepciones para poder notificar al usuario de la aplicación si ocurre algún problema o error durante la ejecución de los procesos.
\end{itemize}
