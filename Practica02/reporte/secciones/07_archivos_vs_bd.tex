\section{Sistema de archivos frente a base de datos}
\subsection{Diferencias entre un sistema de archivos y una base de datos}

Un archivo CSV y una base de datos pueden conservar información de manera
persistente, pero distribuyen de forma distinta las responsabilidades de
organización, control y acceso. En un sistema de archivos, buena parte de esas
responsabilidades recae en el programa que interpreta cada archivo; en un
sistema manejador de bases de datos, forman parte de los servicios propios del
gestor \cite{elmasri2016,silberschatz2019}. Las cinco diferencias relevantes
para PuellaGame se sintetizan a continuación.

\begin{enumerate}[leftmargin=*]
    \item \textbf{Organización y relaciones.} En los CSV, la aplicación define
    columnas, llaves y vínculos entre registros. Una base de datos proporciona
    un esquema explícito y mecanismos para representar relaciones entre
    conjuntos de información.
    \item \textbf{Integridad y consistencia.} En los archivos, todas las reglas
    para impedir valores inválidos, duplicados o referencias incoherentes deben
    programarse y aplicarse correctamente en cada operación. Una base de datos
    puede hacer cumplir dominios, llaves y restricciones de integridad de forma
    centralizada.
    \item \textbf{Consulta y escalabilidad.} Para buscar o combinar información
    en archivos, el programa suele recorrer registros e implementar la lógica
    necesaria. Un gestor ofrece un lenguaje de consulta, índices y un
    optimizador, por lo que puede resolver búsquedas y combinaciones complejas
    con mayor flexibilidad a medida que crece el volumen de datos.
    \item \textbf{Concurrencia y recuperación.} Coordinar varios procesos que
    modifican un mismo archivo exige bloqueos y recuperación desarrollados por
    la aplicación. Un gestor incorpora transacciones, control de concurrencia y
    mecanismos de recuperación para conservar resultados consistentes ante
    accesos simultáneos o fallos.
    \item \textbf{Seguridad y administración.} En un sistema de archivos, el
    control depende principalmente de los permisos del sistema operativo y de
    la aplicación. Una base de datos permite definir usuarios, privilegios y
    vistas, además de centralizar tareas de respaldo y auditoría.
\end{enumerate}

La comparación no implica que un archivo sea incorrecto por definición. El CSV
es un formato textual sencillo e interoperable para intercambiar datos
tabulares \cite{shafranovich2005}; su principal limitación aparece cuando se le
exigen servicios de integridad, consulta y acceso concurrente que el formato no
ofrece por sí mismo.
