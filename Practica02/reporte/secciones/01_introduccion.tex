\section{Introducción}
% Pendiente: delimitar el caso PuellaGame y el propósito del reporte.
El presente reporte detalla la planeación y el desarrollo de un prototipo de software para el centro de entretenimiento familiar "PuellaGame". 
Debido a la alta demanda de clientes durante la temporada vacacional y la urgencia de la administración por agilizar el manejo de datos, 
se ha optado por una solución tecnológica inmediata. Dado que el diseño e implementación de una base de datos formal requiere de un proceso más extenso, 
este proyecto propone un plan alternativo basado en el uso de archivos planos con formato .CSV.

Este prototipo tiene como objetivo principal simular el almacenamiento estructurado de información, permitiendo la gestión (agregar, consultar, editar y eliminar) 
de tres entidades fundamentales: Sucursales, Premios y Clientes. El sistema no solo garantizará la persistencia de los datos, sino que también servirá 
como un paso previo para poblar una futura base de datos robusta una vez que esta sea creada. El desarrollo incluye la validación de tipos de datos, 
el manejo de excepciones para garantizar la estabilidad del sistema y una interfaz de menú interactiva para el usuario final.
